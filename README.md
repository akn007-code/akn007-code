### 📈 AI Powered Stock Evaluation Model

A Python-based stock evaluation model that collects financial data and converts it into scores across **Revenue Growth, Profitability, Valuation, Debt and Cash Flow**.

The aim is to make financial information easier to compare while keeping the scoring process simple and transparent.

**Tools:** Python, financial data APIs and Streamlit.

[View Live App](https://ai-powered-stock-evaluation-model-5rhkaxviqq63fpcamvx7s9.streamlit.app/)
